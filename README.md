# Vision Encoders

ROS 2 package for visual feature extraction using DINOv3, Theia, and other vision backbones.

## Installation

### Prerequisites
- ROS 2 (Humble/Iron/Rolling)
- Python 3.11+ (for DINOv3 compatibility via conda/robostack)
- CUDA-capable GPU (recommended)
